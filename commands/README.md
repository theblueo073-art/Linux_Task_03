# Commands Reference

`commands.sh` is an ordered reference for the Linux Task 03 commands.

It is intentionally not designed to be blindly executed as one script because:

- Some commands require `sudo`.
- `passwd` requires interactive input.
- `su - forensic01` requires interaction.
- `cat` log creation requires manual data entry.
- `less` is interactive.
- The task requires observing and recording access behavior.

Use `workflow/workflow.md` for explanations and verification.

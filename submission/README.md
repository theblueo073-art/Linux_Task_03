# Submission Materials

The Linux Task 03 submission requires:

1. A text file containing the **exact commands used**, named `commands_used.txt`.
2. Screenshots of key terminal outputs, such as grep results, `ls -l`, and permission checks.
3. A short explanation of:
   - What `grep` does (2–3 lines).
   - What `chown` does (2–3 lines).
   - What `usermod` does (2–3 lines).
   - What was learned from trying to access `confidential.txt` after changing ownership.
